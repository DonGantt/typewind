## Escape Hatch

Typewind provides an escape hatch as well, which directly adds the given string to the output. This is not recommended, but can be useful in [some cases](/docs/transpilers/swc#swc-caveat).

```jsx /text_['20px']/
import { tw } from 'typewind-v4'

export default function App() {
  return (
    <button className={tw.raw("bg-blue-500")}>Click Me</button>
  );
}
```

<Tabs items={['Code Output', 'Result']}>
